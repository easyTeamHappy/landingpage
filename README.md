# Landing Page Collection

This project contains multiple landing page templates. Each page is kept in its own folder, and the main entry point remains at the root-level index.html.

## Structure

- index.html — main page with links to all templates
- 01-modern-saas/index.html
- 02-dark-tech/index.html
- 03-corporate/index.html
- 04-minimal/index.html
- 05-creative-agency/index.html
- 06-startup/index.html
- 07-premium/index.html
- 08-product/index.html
- 09-developer/index.html
- 10-ecommerce/index.html
- aura_landing_page/index.html
- business_solutions_landing_page/index.html
- elevate_landing_page/index.html
- nova_landing_page/index.html
- pulse_landing_page/index.html
- vertex_landing_page/index.html

## Usage

Open index.html in a browser to browse all landing page designs. Each card links to its corresponding folder page.
